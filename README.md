# Data Warehouse & Analytics Project

A complete **Data Warehouse and Analytics** project built with **SQL Server**, following a **Bronze → Silver → Gold** architecture.

## 🏗️ Architecture
<img width="1119" height="582" alt="image" src="https://github.com/user-attachments/assets/9e3658a7-73a1-419c-a9c2-b935ccd8a4b4" />


* **Bronze:** Raw data ingestion from CSV files
* **Silver:** Data cleaning, transformation and standardization
* **Gold:** Business-ready dimensional model for analytics

## 🔧 Tech Stack

* **SQL Server & SSMS**
* **SQL / ETL**
* **Data Modeling**
* **Python**
* **Power BI & DAX**
* **Git / GitHub**

## 📊 Analytics

The warehouse is used to analyze:

* Customer behavior
* Product performance
* Sales trends
* Business KPIs

## 📂 Structure

```text
data-warehouse-project/
├── datasets/       # Raw CSV datasets
├── scripts/
│   ├── bronze/     # Data ingestion
│   ├── silver/     # Data cleaning & transformation
│   └── gold/       # Analytical models
├── tests/          # Data quality tests
├── docs/           # Documentation & diagrams
└── README.md
```

## 🎯 Objective

Build a reliable analytical data warehouse and transform raw data into **clean, structured and actionable business insights**.
